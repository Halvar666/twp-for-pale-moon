# Port icon artwork

The blue translation emblem was initially generated with ChatGPT for this project, then manually edited by the maintainer and finally refined with ChatGPT. Provenance was confirmed by the maintainer on 2 November 2026.

- `chatgpt-generated-original-reference.jpg` — initial generated image supplied by the maintainer for provenance.
- `icon-original.png`, `twp-translation-badge-master.png` — artwork saved during the port development process.
- `../chrome/skin/icon-{16,24,32,48,64,128}.png` — executable add-on icon sizes.

These assets were created specifically for TWP for Pale Moon and are not taken from the original TWP icon set.
